# CrownLand.io

Вся игра — один файл `index.html`: код, стили, шрифт, звук и графика внутри.

- **Поиграть:** скачай `index.html` и открой двойным кликом в браузере.
- **CrazyGames:** запакуй `index.html` в ZIP и загрузи как HTML5-игру. SDK площадки подключится сам, вне CrazyGames вместо рекламы показываются заглушки.
